Object-Oriented Programming Lab Practicals (C++)

This repository contains practical programs based on the uploaded OOP Lab Practicals 1–16 document.

## Files

1. Practical-01.cpp — Expressions, input/output and operators
2. Practical-02.cpp — Scope resolution, dynamic memory and manipulators
3. Practical-03.cpp — Type casting and function defined inside a class
4. Practical-04.cpp — Member functions defined outside the class
5. Practical-05.cpp — Inline function
6. Practical-06.cpp — Friend function (two classes)
7. Practical-07.cpp — Static data member and static member function
8. Practical-08.cpp — Array of objects
9. Practical-09.cpp — Constructors and destructor
10. Practical-10.cpp — Single inheritance (example provided in source document)
11. Practical-11.cpp — Virtual base class
12. Practical-12.cpp — Pointer to object and this pointer
13. Practical-13.cpp — Pointer to derived class
14. Practical-14.cpp — Function overloading
15. Practical-15.cpp — Unary operator overloading using a member function
16. Practical-16.cpp — Binary operator overloading using a member function

## Run a practical

Compile one file at a time with `g++ Practical-01.cpp -o practical` and run it with `./practical`. Each file has its own `main()` function.

Note: Where the supplied document contains multiple sample programs under one experiment, the main example is included in the numbered file. The document's examples are followed without adding topics not shown in the source.
