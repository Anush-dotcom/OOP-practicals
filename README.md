Object-Oriented Programming Lab Practicals (C++)

This repository contains practical programs based on the OOP lab practicals.

## Practical files

1. `Practical-01.cpp` — Expressions, input/output and operators
2. `Practical-02.cpp` — Scope resolution, dynamic memory and manipulators
3. `Practical-03.cpp` — Implicit/explicit type casting and a function inside a class
4. `Practical-04.cpp` — Member functions defined outside the class
5. `Practical-05.cpp` — Inline function
6. `Practical-06.cpp` — Friend function using two classes
   - `Practical-06-Single-Class-Friend.cpp` — Friend function using one class
7. `Practical-07.cpp` — Static data member and static member function
8. `Practical-08.cpp` — Array of objects
9. `Practical-09.cpp` — Constructors and destructor
10. `Practical-10.cpp` — Single inheritance example shown in the source document
11. `Practical-11.cpp` — Virtual base class
   - `Practical-11-Derived-Constructor.cpp` — Constructor in a derived class
12. `Practical-12.cpp` — `this` pointer example
   - `Practical-12-Object-Pointer-Sample.cpp` — Pointer to object
13. `Practical-13.cpp` — Pointer to derived class in single inheritance
14. `Practical-14.cpp` — Function overloading
15. `Practical-15.cpp` — Unary operator overloading using a member function
   - `Practical-15-Friend-Function.cpp` — Unary operator overloading using a friend function
16. `Practical-16.cpp` — Binary operator overloading using a member function
   - `Practical-16-Friend-Function.cpp` — Binary operator overloading using a friend function
17. `Practical-17.cpp` — Virtual function and pure virtual function

## Compile and run

Compile one file at a time with `g++ Practical-01.cpp -o practical` and run it with `./practical`. Replace the filename with the practical you want to run. Each `.cpp` file is a separate program and should be compiled separately.

The programs follow the supplied practical material where applicable.
